# 📊Sales_performance_data
An Excel dashboard project focused on sales performance analysis using KPIs, Pivot Tables, charts, and slicers. The project analyzes Revenue, COGS, Profit, Customers, Product Profitability, Sales Rep Performance, City-level COGS, and Monthly Customer trends with an interactive dashboard.  

## 📈 KPIs Calculated
- 💰 Revenue
- 📦 COGS
- 📊 Profit
- 👥 Customers

## 📉 Dashboard Visualizations
- 🛍️ Product by Profit
- 🧑‍💼 Sales Rep by Revenue
- 🏙️ City by COGS
- 📅 Monthly Customer Trends

## 🧰 Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers

## 🎛️ Interactive Filters
- 🌍 Region Slicer
- 🗂️ Category Slicer
